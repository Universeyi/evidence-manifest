# Survey: published repeated-run (same config x >=2 trials x same tasks) per-task outcomes in agent benchmarks
Date: 2026-09-05. Criterion (strict): downloadable per-task per-trial verdicts for the SAME agent configuration run >=2 times on the SAME tasks. tau2-bench excluded (done separately).

## Status: COMPLETE 2026-09-05 (findings log below was written incrementally; summary table at end)

## Findings log

### tau-bench v1 (sierra-research/tau-bench, historical_trajectories/) -- SATISFIES
- Verified by download 2026-09-05. Four files: gpt-4o-airline.json (50 tasks x 4 trials = 200 records), gpt-4o-retail.json (115 x 4 = 460), sonnet-35-new-airline.json (50 x 8 = 400), sonnet-35-new-retail.json (115 x 8 = 920). Same agent config (tool-calling agent, gpt-4o user sim), same tasks, trials 0..3 or 0..7.
- URL: https://github.com/sierra-research/tau-bench/tree/main/historical_trajectories (raw: https://raw.githubusercontent.com/sierra-research/tau-bench/main/historical_trajectories/<file>.json). Committed 2024-11-23 (7362a17).
- Format: JSON list of {task_id:int, trial:int, reward:0/1 float, info:{task, source, user_cost, reward_info:{reward, info{r_actions,gt_data_hash}, actions[]}}, traj:[{role,content,(tool_calls)}...]}. Per-task per-trial verdict = reward keyed by (task_id, trial). Full trajectories included.
- Missing: per-step tokens (only user_cost aggregate), no timestamps, no explicit termination reason (inferable from traj end), no evaluator commit/version stamped in file (only repo commit).
- Licence: MIT (repo LICENSE, Sierra 2024).

### Terminal-Bench 2.0 (tbench.ai leaderboard; HF harborframework/terminal-bench-2-leaderboard; harbor) -- SATISFIES (strongest)
- Policy: every task evaluated with >=5 trials (-k 5); ATIF trajectories required for all passing trials (tbench.ai/news/leaderboard-integrity-update). Leaderboard shows resolution rate with 95% CI whiskers.
- Raw submissions: HF dataset https://huggingface.co/datasets/harborframework/terminal-bench-2-leaderboard (Apache-2.0; last modified 2026-05-15). 76 submission dirs under submissions/terminal-bench/2.0/<agent>__<model>/ each with metadata.yaml + >=1 job dir(s) (config.json + <task>__<id>/{config.json,result.json,agent/,verifier/}). Verified 2026-09-05 e.g. .../Terminus2__Claude-Opus-4.6/2026-02-05__16-08-28/adaptive-rejection-sampler__gmpg6m3/result.json.
- result.json keys (harbor): id, task_name, trial_name, task_id{git_url,git_commit_id,path}, task_checksum, config{agent{name,model_name,kwargs{reasoning_effort,temperature}},environment,verifier,job_id}, agent_info{name,version,model_info}, agent_result{n_input_tokens,n_cache_tokens,n_output_tokens,cost_usd,metadata{n_episodes,api_request_times_msec[]}}, verifier_result{rewards{reward}}, exception_info, started_at/finished_at, environment_setup/agent_setup/agent_execution/verifier {started_at,finished_at}. => per-trial verdict = verifier_result.rewards.reward keyed by (task_name, trial_name); trial-level tokens (not per-step in result.json, but ATIF trajectory in agent/ has per-step usage); timestamps yes; termination reason via exception_info; evaluator commit = task_id.git_commit_id + task_checksum + harbor version in config.
- Convenience repackagings: (a) HF yoonholee/terminalbench-trajectories (Apache-2.0): 52,104 trials, 89 tasks, 109 agent/model combos, columns task_name, agent, model, reward(0/1), duration_seconds, input/output/cache tokens, cost_cents, trial_name, trial_id, started_at, ended_at, steps(JSON). Verified on shard 0: trials per (agent,model,task) = 5 for 4085 cells, 10 for 377, 12 for 93, etc. (b) HF harithoppil/terminal-bench-2-trajectories (Apache-2.0) jsonl. (c) github fsndzomga/efficient-benchmarking-ai-agents data/terminal_bench_2_0_tasks.csv (MIT): 9,167 rows = (agent,model,task) with trials, successes (aggregated, not per-trial).
- Older Terminal-Bench-Core 0.1.1 leaderboard: github laude-institute/terminal-bench-leaderboard results/terminal-bench-core@0.1.1/<YYYYMMDD_agent_model>/<run_1..5>/results.json ; 25 submissions; results.json has results[]{trial_name,task_id,is_resolved,failure_mode,parser_results,total_input_tokens,total_output_tokens,trial_started_at,...}. 5 runs x ~80 tasks per submission. Licence: not stated in repo API (check).
